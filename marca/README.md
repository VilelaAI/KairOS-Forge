# Marca KairOS-Forge

Arquivos da logo, em SVG com o texto convertido em contorno (Inter Bold): abrem iguais em qualquer máquina, sem a fonte instalada. As cores são fixas em cada arquivo, então escolha a versão pela cor do fundo.

| Arquivo | Onde usar |
|---|---|
| `kairos-forge-horizontal.svg` | Padrão, sobre fundo escuro |
| `kairos-forge-horizontal-claro.svg` | Sobre fundo claro |
| `kairos-forge-assinatura.svg` | Com "A FÁBRICA DE SOFTWARE AGÊNTICA", fundo escuro |
| `kairos-forge-assinatura-claro.svg` | Com a assinatura, fundo claro |
| `kairos-forge-simbolo.svg` | Só o símbolo, quando o nome já aparece perto |
| `kairos-forge-icone.svg` | Favicon, ícone de app, avatar, marketplace |
| `kairos-forge-horizontal-mono-branco.svg` | Uma cor, sobre foto ou cor de terceiros |
| `kairos-forge-horizontal-mono-profundo.svg` | Uma cor no claro: impressão, carimbo |
| `kairos-forge-simbolo-mono-branco.svg` | Símbolo em uma cor, fundo escuro |
| `kairos-forge-simbolo-mono-profundo.svg` | Símbolo em uma cor, fundo claro |

Paleta: Roxo Neon `#8B5CF6`, Azul Elétrico `#06B6D4`, Rosa Magenta `#EC4899`, Azul Profundo `#0B1026` e Off White `#F8FAFC`; o gradiente do símbolo passa pelo anil `#3F5CF9`.

Regras de uso:

- Deixe livre em volta da marca a altura de uma onda do símbolo.
- Tamanho mínimo: símbolo com 24 px de altura, horizontal com 120 px de largura; abaixo disso, use o ícone.
- Em prosa, o nome é **KairOS-Forge**; em código e comando, `kairos-forge`.
- Não troque as cores do gradiente, não gire nem espelhe o símbolo e não recomponha o nome em outra fonte.

Esta pasta fica fora de `docs/` de propósito: o `release.py` espelha `docs/` em `plugin/`, e a marca não precisa ir junto com o plugin distribuído.
